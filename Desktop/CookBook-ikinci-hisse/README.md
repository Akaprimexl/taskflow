# CookBook — Üçüncü hissə

Tam layihə qovluğu. Layihəni VS Code-da açın, terminalda npm install və sonra npm run dev yazın. package.json olan qovluq əsas qovluqdur.

Ana səhifədə TheMealDB API-dən kateqoriyalar və şəkillər göstərilir. Resept axtarışı, reseptin ID ilə detalları, kateqoriya filtri, loading və error səhifələri də daxildir.

API üçün internet bağlantısı tələb olunur. TheMealDB test açarı 1 istifadə edilir. Sənədlər: https://www.themealdb.com/documentation
